# Mechanical

This folder covers the mechanical design and manufacturing of the arm: CAD, gearboxes, the base pivot mechanism, 3D printing, and assembly.

## Structure

- [`cad/`](cad/README.md) — Fusion 360 planning CAD (start → progress → complete version)
- [`gearbox/`](gearbox/README.md) — Custom printed planetary gearboxes (prototype phase, joint 1/base, joint 2)
- [`base-pivot/`](base-pivot/README.md) — Base pivot mechanism (bearing-based innovation)
- [`manufacturing/`](manufacturing/README.md) — 3D printing optimization and printed parts
- [`assembly/`](assembly/README.md) — First test assemblies
