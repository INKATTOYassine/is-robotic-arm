# Gearbox

Custom 3D-printed planetary gearboxes, one per stepper-driven joint.

## Subfolders

- [`prototype/`](prototype/README.md) — Early prototyping phase (first gearbox design, iterating on backlash/tooth profile)
- [`joint1-base/`](joint1-base/README.md) — Final gearbox for the base joint (1:16 ratio)
- [`joint2/`](joint2/README.md) — Final gearbox for joint 2 (1:64 ratio — 1:16 wasn't enough torque/precision for this joint)

## Ratio comparison

Joint 2 initially used the same 1:16 ratio as the base, but this proved insufficient, so a 1:64 gearbox was designed instead. See [`joint2/`](joint2/README.md) for the side-by-side size comparison.
